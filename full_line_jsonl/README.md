# full JSONL

一词一行 JSON，目录和 [full TSV](../full_line_tsv/README.md) 对齐。

```
{simple,sentence,full}/{正序,乱序}/四级.jsonl
```

| 目录 | 一行里有什么 | 示例 |
|------|----------------|------|
| `simple/` | 词条、释义、短语 | [sample_simple.jsonl](./sample_simple.jsonl) |
| `sentence/` | + 音标、例句 | [sample_sentence.jsonl](./sample_sentence.jsonl) |
| `full/` | 完整结构（同近义、真题等） | [sample_full.jsonl](./sample_full.jsonl) |

乱序不并进正序。转 TSV：`python3 scripts/json_to_line.py --check`
